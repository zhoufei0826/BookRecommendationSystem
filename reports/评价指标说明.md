# 推荐系统评价指标说明

在推荐系统、分类与排序任务中，常用 **P（Precision，精确率）**、**R（Recall，召回率）**、**F1（F1-Score）** 来衡量模型效果。当存在多个类别、多个用户或多个标签时，还需区分 **micro 平均** 与 **macro 平均** 等聚合方式。

本文重点介绍 **micro-P、micro-R、micro-F1** 的含义与计算方法，并对比 macro 平均与实例级（instance-level）平均，帮助你正确选择和使用这些指标。

---

## 1. 基础概念：P、R、F1

以二分类任务为例，给定一个用户的推荐列表与该用户的真实交互（相关）物品集合：

| | 真实相关 | 真实不相关 |
|---|---|---|
| **推荐** | TP（真正例） | FP（假正例） |
| **未推荐** | FN（假反例） | TN（真反例） |

其中：

- **TP (True Positive)**：推荐了，且用户确实感兴趣（命中）
- **FP (False Positive)**：推荐了，但用户不感兴趣（误报）
- **FN (False Negative)**：没推荐，但用户其实感兴趣（漏报）

### 1.1 Precision（精确率）

> “在所有被推荐的物品中，有多少比例是用户真正感兴趣的？”

$$\text{Precision} = \frac{TP}{TP + FP}$$

### 1.2 Recall（召回率）

> “在所有用户真正感兴趣的物品中，有多少比例被我们推荐出来了？”

$$\text{Recall} = \frac{TP}{TP + FN}$$

### 1.3 F1-Score

> Precision 与 Recall 的调和平均，用于在两者之间取得平衡。

$$\text{F1} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2TP}{2TP + FP + FN}$$

---

## 2. 什么是 Micro 平均？

当有多个用户、多个类别或多个标签时，不能简单地对每个用户/类别的 P、R 分别求平均，因为不同用户的交互数量差异很大（有的用户交互 100 件物品，有的只有 1 件）。

**Micro 平均（微观平均 / 全局平均）** 的做法是：

1. 在所有用户/所有类别中，**先把 TP、FP、FN 全局累加**；
2. 然后再用累加后的总 TP、总 FP、总 FN 来计算 P、R、F1。

这样，交互数量多的用户会对最终指标产生更大的权重，更符合整体推荐质量的直觉。

---

## 3. Micro-P、Micro-R、Micro-F1 的定义与计算

假设有 $m$ 个用户，对于第 $u$ 个用户：

- $TP_u$：该用户被正确推荐的物品数
- $FP_u$：该用户被错误推荐的物品数
- $FN_u$：该用户漏掉的相关物品数

### 3.1 计算步骤

**第 1 步：全局累加**

$$\begin{aligned}
TP_{\text{total}} &= \sum_{u=1}^{m} TP_u \\
FP_{\text{total}} &= \sum_{u=1}^{m} FP_u \\
FN_{\text{total}} &= \sum_{u=1}^{m} FN_u
\end{aligned}$$

**第 2 步：计算 Micro-P**

$$\text{Micro-P} = \frac{TP_{\text{total}}}{TP_{\text{total}} + FP_{\text{total}}}$$

**第 3 步：计算 Micro-R**

$$\text{Micro-R} = \frac{TP_{\text{total}}}{TP_{\text{total}} + FN_{\text{total}}}$$

**第 4 步：计算 Micro-F1**

$$\text{Micro-F1} = 2 \times \frac{\text{Micro-P} \times \text{Micro-R}}{\text{Micro-P} + \text{Micro-R}}$$

等价地，直接用全局 TP/FP/FN 计算：

$$\text{Micro-F1} = \frac{2 \cdot TP_{\text{total}}}{2 \cdot TP_{\text{total}} + FP_{\text{total}} + FN_{\text{total}}}$$

---

## 4. Macro-P、Macro-R、Macro-F1 的定义与计算

与 Micro 平均不同，**Macro 平均（宏观平均）** 是**先分别计算每个用户（或每个类别）的 P、R、F1，然后再对这些指标求算术平均**。它不关心用户交互数量的多少，每个用户的权重完全相等。

假设有 $m$ 个用户，对于第 $u$ 个用户：

- $TP_u$：该用户被正确推荐的物品数
- $FP_u$：该用户被错误推荐的物品数
- $FN_u$：该用户漏掉的相关物品数

### 4.1 计算步骤

**第 1 步：分别计算每个用户的 P、R、F1**

$$\begin{aligned}
P_u &= \frac{TP_u}{TP_u + FP_u} \\
R_u &= \frac{TP_u}{TP_u + FN_u} \\
F1_u &= \frac{2 \cdot P_u \cdot R_u}{P_u + R_u} = \frac{2 \cdot TP_u}{2 \cdot TP_u + FP_u + FN_u}
\end{aligned}$$

> 注意：当分母为 0 时（例如用户没有任何推荐且没有相关物品），该用户的 P、R、F1 通常定义为 0。

**第 2 步：对所有用户的指标求算术平均**

$$\begin{aligned}
\text{Macro-P} &= \frac{1}{m} \sum_{u=1}^{m} P_u \\
\text{Macro-R} &= \frac{1}{m} \sum_{u=1}^{m} R_u \\
\text{Macro-F1} &= \frac{1}{m} \sum_{u=1}^{m} F1_u
\end{aligned}$$

### 4.2 宏观平均的特点

| 特点 | 说明 |
|------|------|
| **等权重** | 每个用户对最终指标的贡献相同，无论其交互数量多少 |
| **关注长尾** | 对冷启动用户、交互少的用户更敏感，不会被活跃用户主导 |
| **直观公平** | 更能反映“平均每个用户”的推荐体验 |
| **计算方式** | 先算单个指标，再求平均（与 Micro 先累加再计算相反） |

### 4.3 与 Micro 平均的关系

- **Micro-F1** 通常 **不等于** Macro-F1（各用户 F1 的简单平均）
- 当所有用户的样本数（TP+FP+FN）完全相同时，Micro 和 Macro 的结果会一致
- 通常情况下，Micro-F1 更偏向交互多、活跃度高的用户；Macro-F1 更反映普通用户的平均表现

## 5. 计算示例

假设系统有 3 个用户，Top-K 推荐后的结果如下：

| 用户 | 推荐物品集 | 真实相关物品集 | TP | FP | FN |
|:---|:---|:---|:---:|:---:|:---:|
| 用户 A | {1, 2, 3, 4, 5} | {1, 2, 6, 7} | 2 | 3 | 2 |
| 用户 B | {10, 11, 12} | {10, 11, 12, 13} | 3 | 0 | 1 |
| 用户 C | {20} | {} | 0 | 1 | 0 |

### 4.1 各用户单独计算（宏观视角）

| 用户 | Precision | Recall | F1 |
|:---|:---:|:---:|:---:|
| A | 2/5 = 0.40 | 2/4 = 0.50 | 0.444 |
| B | 3/3 = 1.00 | 3/4 = 0.75 | 0.857 |
| C | 0/1 = 0.00 | 0/0 = undefined（定义为 0） | 0.000 |

Macro-P = (0.40 + 1.00 + 0.00) / 3 ≈ 0.467  
Macro-R = (0.50 + 0.75 + 0) / 3 ≈ 0.417  
Macro-F1 = (0.444 + 0.857 + 0) / 3 ≈ 0.434

### 4.2 Micro 平均计算（全局累加）

$$\begin{aligned}
TP_{\text{total}} &= 2 + 3 + 0 = 5 \\
FP_{\text{total}} &= 3 + 0 + 1 = 4 \\
FN_{\text{total}} &= 2 + 1 + 0 = 3
\end{aligned}$$

$$\text{Micro-P} = \frac{5}{5 + 4} = \frac{5}{9} \approx 0.556$$

$$\text{Micro-R} = \frac{5}{5 + 3} = \frac{5}{8} = 0.625$$

$$\text{Micro-F1} = \frac{2 \times 5}{2 \times 5 + 4 + 3} = \frac{10}{17} \approx 0.588$$

> 注意：Micro-F1 **不等于** 各用户 F1 的简单平均（0.434），因为交互多的用户（如用户 B）在 micro 平均中权重更高。

---

## 6. Micro vs Macro vs 实例级平均

| 维度 | Micro 平均 | Macro 平均 | 实例级平均（Instance-level / User-level） |
|:---|:---|:---|:---|
| **计算方式** | 先累加 TP/FP/FN，再算 P/R/F1 | 分别算每个用户/类别的 P/R/F1，再求算术平均 | 先算每个用户的 F1（或 P/R），再平均 |
| **权重** | 交互多的样本权重大 | 每个样本权重相等 | 每个样本权重相等 |
| **适用场景** | 类别/用户样本数不平衡，关注整体表现 | 希望每个类别/用户地位平等 | 评估每个用户的平均体验 |
| **优点** | 对不平衡数据鲁棒，反映整体命中量 | 不会被大类/活跃用户主导 | 更关注“每个用户”都能获得好推荐 |
| **缺点** | 冷门用户/长尾类别贡献被淹没 | 小样本类别噪声影响大 | 活跃用户与冷门用户同等对待，可能偏离整体效果 |

---

## 7. 在推荐系统中的常见使用场景

| 指标 | 说明 | 适用场景 |
|:---|:---|:---|
| **Precision@K** | Top-K 推荐列表中的精确率 | 关注推荐列表的“干净度”，如广告推荐 |
| **Recall@K** | Top-K 推荐列表中的召回率 | 关注是否把用户感兴趣的物品都召回，如召回阶段评估 |
| **F1@K** | Precision@K 与 Recall@K 的调和平均 | 需要同时兼顾精确率与召回率 |
| **Micro-F1@K** | 全局累加后的 F1 | 多标签分类、多类排序、整体推荐质量评估 |
| **Macro-F1** | 各用户/各类别 F1 的简单平均 | 类别不平衡时，希望每个类别都被重视 |

## 8. 代码示例（Python）

```python
import numpy as np

def compute_micro_metrics(y_true, y_pred):
    """
    计算 micro-P, micro-R, micro-F1
    
    参数:
        y_true: list of sets, 每个用户真实相关物品集合
        y_pred: list of sets, 每个用户推荐物品集合
    
    返回:
        dict: 包含 micro_p, micro_r, micro_f1
    """
    assert len(y_true) == len(y_pred)
    
    tp_total = 0
    fp_total = 0
    fn_total = 0
    
    for true_set, pred_set in zip(y_true, y_pred):
        tp = len(true_set & pred_set)      # 交集
        fp = len(pred_set - true_set)      # 推荐了但不相关
        fn = len(true_set - pred_set)      # 相关但没推荐
        
        tp_total += tp
        fp_total += fp
        fn_total += fn
    
    micro_p = tp_total / (tp_total + fp_total) if (tp_total + fp_total) > 0 else 0.0
    micro_r = tp_total / (tp_total + fn_total) if (tp_total + fn_total) > 0 else 0.0
    micro_f1 = (2 * micro_p * micro_r / (micro_p + micro_r)) if (micro_p + micro_r) > 0 else 0.0
    
    return {
        "micro_p": micro_p,
        "micro_r": micro_r,
        "micro_f1": micro_f1,
        "tp": tp_total,
        "fp": fp_total,
        "fn": fn_total
    }


# 使用示例
y_true = [{1, 2, 6, 7}, {10, 11, 12, 13}, set()]
y_pred = [{1, 2, 3, 4, 5}, {10, 11, 12}, {20}]

result = compute_micro_metrics(y_true, y_pred)
print(result)
# 输出: {'micro_p': 0.555..., 'micro_r': 0.625, 'micro_f1': 0.588..., ...}
```

## 9. 总结

| 指标 | 核心含义 |
|:---|:---|
| **Micro-P** | 全局所有推荐中，真正命中的比例 |
| **Micro-R** | 全局所有相关物品中，被推荐出来的比例 |
| **Micro-F1** | Micro-P 与 Micro-R 的调和平均，衡量整体推荐质量 |

**使用建议**：

- 若希望评估**整体推荐系统**的命中效率，且数据存在用户活跃度差异，优先使用 **Micro-F1**。
- 若希望**每个用户都能获得满意推荐**，不希望活跃用户掩盖冷启动用户的表现，可参考 **Macro-F1** 或 **实例级平均 F1**。
- 在实际报告中，建议**同时展示多个指标**，并说明平均方式，避免单一指标产生误导。
